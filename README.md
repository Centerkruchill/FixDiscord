## ⚙️ Использование

1. Настройте Безопасный DNS (Secure DNS).
    * В Chrome включите "Использовать безопасный DNS" и выберите поставщика, отличного от "Поставщик по умолчанию".
    * В Firefox откройте "DNS через HTTPS", выберите режим "Персональный", затем "Выбрать провайдера/поставщика" и вручную укажите URL. Например: `https://dns.google/dns-query`, поскольку Cloudflare может быть заблокирован.
    * Windows 11 позволяет включить Secure DNS непосредственно в настройках системы — [инструкция](https://remontka.pro/dns-over-https-windows-11/). Для пользователей Windows 11 этот способ рекомендуется.
    * На роутерах Keenetic включите параметр "Транзит запросов". Если его отключить, Secure DNS на компьютере может работать неправильно или не настроиться.

2. Загрузите zip/rar-архив с [последнего релиза](https://github.com/Centerkruchill/zapret-discord-youtube/releases/latest).

3. Откройте свойства архива и отметьте "Разблокировать". При распаковке через 7-Zip или PeaZip этот пункт можно не выполнять.

4. Извлеките файлы в каталог, путь к которому не содержит кириллицу и специальные символы.

5. Запустите нужный скрипт:
    * Для поиска рабочей стратегии откройте **`service.bat`** → `Run Tests` → `Standard tests` → `All configs`.
    * Для добавления стратегии в автозапуск выберите **`service.bat`** → `Install Service` → подходящую стратегию.

## ℹ️ Кратко о файлах

- [**`general.bat ...`**](./general.bat) запускает стратегию вручную.

  Такой запуск удобен для проверки стратегий. Результат зависит от множества условий, поэтому **перебирайте варианты (ALT, FAKE и другие), пока не найдёте подходящий именно вам**.

- [**`service.bat`**](./service.bat) отвечает за автозапуск и дополнительные операции:
  - <ins>**`Install Service`** — добавить выбранную стратегию в автозапуск Windows (services.msc).</ins>
  - **`Remove Services`** — удалить стратегию и WinDivert из служб.
  - **`Check Status`** — посмотреть состояние обхода и служб, включая автозапущенную стратегию и WinDivert.
  - **`Game Filter`** — изменить режим обхода для игр и других сервисов, использующих UDP и TCP на портах выше 1023.  
  **После изменения режима стратегию нужно перезапустить.**  
  В скобках отображается текущее состояние: включено или выключено.
  - **`IPSet Filter`** — включить или выключить обход сервисов, перечисленных в `ipset-all.txt`.  
  Опция полезна при проверке ресурса, который без zapret работает.  
  Возможные статусы:
    - `none` — ни один IP не проходит проверку;
    - `loaded` — проверяется принадлежность IP списку;
    - `any` — под фильтр попадает любой IP.
  - **`Auto-Update Check`** — включить или отключить автоматическую проверку обновлений.
  - **`Replace active fakes`** — заменить выбранный активный фейк другим файлом из каталога `bin`.
  - **`Update IPSet List`** — получить актуальный `ipset-all.txt` из репозитория.
  - **`Update Hosts File`** — обновить hosts <ins>для восстановления веб-версии Telegram и подключения к голосовому чату Discord.</ins>
  - **`Check for Updates`** — вручную проверить наличие обновлений.
  - **`Run Diagnostics`** — проверить распространённые причины неработоспособности zapret.  
  В конце диагностики можно очистить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда помогает при внезапной остановке работы Discord.
  - **`Run Tests`** — открыть проверку стратегий:
    - `Standard tests` — протестировать сайты из `utils/targets.txt`;
    - `DPI checkers` — проверить DPI у разных провайдеров, включая Cloudflare и Amazon.

## ☑️ Распространённые вопросы и проблемы

### После запуска `general*` ничего не происходит

При запуске стратегии отдельным bat-файлом, а не через service, должен появиться процесс winws.exe. Его можно увидеть на панели задач.  
Если этого не случилось, обратитесь к [#522](https://github.com/Centerkruchill/zapret-discord-youtube/issues/522).

### Рабочая стратегия не находится

1. Откройте командную строку от имени администратора.
2. Выполните по очереди:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`

3. Перезагрузите компьютер.

### Не открывается Telegram в браузере

В **`service.bat`** выберите **`Update hosts file`**. Если текущий hosts окажется устаревшим, программа предложит обновить его вручную:  
  - скопируйте весь текст из открытого блокнота;
  - от имени администратора откройте текстовым редактором файл `hosts` в появившейся папке;
  - вставьте скопированный текст в конец `hosts` или замените ранее добавленный аналогичный фрагмент;
  - сохраните файл и проверьте соединение ещё раз. Если результата нет, убедитесь, что `hosts` действительно сохранился.

#### Результат не гарантируется. Если способ не помог, используйте [Desktop-версию Telegram](https://github.com/telegramdesktop/tdesktop/releases) с [локальным прокси](https://github.com/Centerkruchill/tg-ws-proxy) или любым публичным прокси.

### Обход не запускается или перестал работать

> [!IMPORTANT]
> **Стратегии не обязательно работают постоянно.**
> Конкретный вариант может некоторое время обходить блокировку, а затем перестать работать после его обнаружения.
> Здесь доступно много стратегий. Если ни одна не подходит, создайте новую на основе одной из них, изменив параметры.
> Описание параметров находится [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- Убедитесь, что `service.bat` → `Run Diagnostics` не показывает ошибок.
- Проверьте, внесён ли адрес нужного ресурса в списки доменов или IP.
- Переберите другие стратегии, включая **`ALT`** и **`FAKE`**.
- Выполните полную переустановку по инструкции ниже.
- Дополнительная информация: [#765](https://github.com/Centerkruchill/zapret-discord-youtube/issues/765).

### Полная переустановка или обновление

- Сначала сохраните добавленные вами ресурсы и данные.
- Перезагрузите устройство.
- Выполните `service.bat` → `Remove Services`.
- Запустите `service.bat` → `Run Diagnostics`; при наличии ошибок устраните их, затем в конце выберите Y.
- Удалите каталог zapret.
- Скачайте свежий архив `zapret-discord-youtube-...` со [страницы релизов](https://github.com/Centerkruchill/zapret-discord-youtube/releases).
- Нажмите правой кнопкой по архиву и откройте свойства. Если внизу справа есть "Разблокировать", отметьте этот пункт, нажмите "Применить" и "ОК".
- Распакуйте архив в новый каталог в корне диска, без пробелов и специальных символов.
- По очереди проверяйте разные `general`-скрипты. Если интернет-ресурсы не открываются, закройте программу через значок замка на панели задач и попробуйте следующую стратегию.
- Найдя рабочий вариант, добавьте его в автозапуск через `service.bat` → `Install Service` → нужная стратегия.

### Игра или приложение не работает при включённом zapret

- В `service.bat` проверьте, что `Game Filter` имеет значение **`disabled`**, а `IPSet Filter` — **`none`**. Иначе фильтрация может затронуть неожиданные ресурсы.

### Античит сообщает о WinDivert

- Инструкция доступна [здесь](https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide).

### Windows 7 требует цифровую подпись драйвера WinDivert

- В каталоге [`bin`](./bin) замените `WinDivert.dll` и `WinDivert64.sys` одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7).

### После удаления через [**`service.bat`**](./service.bat) WinDivert всё ещё есть среди служб

1. Узнайте имя службы в командной строке Windows (Win+R → `cmd`):

```cmd
driverquery | find "Divert"
```

2. Затем остановите и удалите её, подставив имя из первого шага:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте настройку [Secure DNS](#%EF%B8%8Fиспользование).
- Отключите блокировщик рекламы: известно, что YouTube начал с ними бороться.
- Перезапустите проверку всех остальных стратегий, особенно если прежняя недавно перестала работать.
- См. также [#251](https://github.com/Centerkruchill/zapret-discord-youtube/discussions/251).

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что включён [Secure DNS](#%EF%B8%8Fиспользование).
- Сначала желательно определить стратегию, на которой открывается YouTube, и запустить её.
- В `service.bat` выполните `Run Diagnostics`, затем очистите кэш Discord.
- Проверьте приложение Discord и выясните, помогла ли очистка.
- Откройте Discord в браузере: https://discord.com/app. Если веб-версия работает, можно пользоваться ею.
- Если сайт тоже недоступен, снова проверьте все стратегии: бывает, что YouTube работает на одной, а Discord — нет.
- См. также [#252](https://github.com/Centerkruchill/zapret-discord-youtube/discussions/252).

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Попробуйте [tg-ws-proxy](https://github.com/Centerkruchill/tg-ws-proxy).
- Также можно использовать бесплатные MTProto-прокси из интернета.

### Не работают игры

Игр много, поэтому проверить и исправить каждую из них невозможно.

Наиболее универсальная последовательность:
- обновить ipset через `service.bat` и включить `Game Filter`;
- если это не помогло, дополнительно включить `ipset any`.

Учтите: режим `ipset any` способен нарушить открытие многих сайтов. Не оставляйте его включённым постоянно. Вместо этого определите все IP-адреса, которые использует игра, и внесите их в `ipset-all.txt`.

Если результат отсутствует, создайте обсуждение в разделе [Discussions](https://github.com/Centerkruchill/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### Ответа на проблему нет

- Оформите её [здесь](https://github.com/Centerkruchill/zapret-discord-youtube/issues).

## 🗒️ Добавление адресов других ресурсов

Списки обхода можно расширять самостоятельно:
- домены добавляйте в **`list-general-user.txt`**; поддомены учитываются автоматически;
- домены, которые нужно исключить, указывайте в **`list-exclude-user.txt`** — например, когда сеть есть в `ipset-all.txt`, но конкретный домен фильтровать не требуется;
- IP-адреса и подсети добавляйте в **`ipset-all.txt`**;
- исключения для IP и подсетей записывайте в **`ipset-exclude-user.txt`**.
  - Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`.
